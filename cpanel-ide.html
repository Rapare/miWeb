Can this run on cPanel?

Yes — this interface is a static HTML/CSS concept, so it can be hosted on cPanel as a normal website. To make it fully functional (save files, execute code, terminal access), you will also need a backend service and secure sandboxing, which is not provided by basic shared-hosting cPanel plans.
